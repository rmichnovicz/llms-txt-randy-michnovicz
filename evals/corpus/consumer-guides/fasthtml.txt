# FastHTML

> FastHTML is a Python library for building HTML-first, server-rendered web applications using FastTags, Starlette, Uvicorn, and HTMX.

FastHTML is aimed at web applications rather than API-first services. Its routing may feel familiar to FastAPI users, but FastHTML syntax is not FastAPI-compatible.

Live reloading is intended for development and should be turned off for production deployment.

## Overview

- [FastHTML home](<https://www.fastht.ml/>): Overview, examples, and FAQ covering use cases, deployment, and the roles of Python, JavaScript, and HTMX.
